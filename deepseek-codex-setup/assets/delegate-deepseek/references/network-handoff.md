# 网络与共享目录交接

适用于任务材料位于 UNC 路径、映射网络盘，或需访问外网的情形。启动目录预授权不等于子进程具有 SMB/联网权限。实际故障中，共享目录在主代理可读，在 Windows 工作代理内却被拒绝；设置工作目录失败后，相对路径落到了 PowerShell 程序目录。

## 分派前

- 主代理先核验真实路径和自身访问能力。UNC 路径以两个反斜杠开头；有盘符不代表本地盘，可检查该盘的网络映射。只检查本次所需目录，不枚举其他网络盘。
- 当前 Broker 对网络或额外权限申请有固定拒绝分支。对于已知受阻的共享任务，在首次 Broker 工具调用前，为该任务新建独立的本地工作目录，只复制已获委派同意、确实需要的具体文件，或直接提供必要文本。不要复制整个数据集、凭据、登录状态或无关文件。
- 保存原路径与本地相对路径、原始哈希的映射，保留必要相对目录结构；校验副本与原文件内容一致。大文件可先由主代理在原位置计算所需摘要/统计，不为交接自动搬运全部数据。
- 对本地执行目录运行 `ensure_workspace.ps1`，使用其规范化 `root` 作为 `spawn.cwd`。告知工作代理材料是本地任务副本、可读文件清单、允许写入的结果/临时路径、普通本地命令范围和验收方法。

## 执行和写回

- 在交接提示中要求工作代理先检查实际目录；目录不符或首次 `Access denied` 时立即停止并报告。不要继续使用相对路径，不改试其他网络盘、凭据、命令变体或 `require_escalated`。
- 主代理需要的公开网页或远程数据，在原任务已授权的范围内自行获取，再交付必要内容及来源；对登录、付费、上传、发布等操作分别遵守用户授权。
- DeepSeek 只处理本地副本。主代理检查输出和差异；写回原文件前核对原哈希没有变化，并确认原任务确实授权该修改。发生并发修改时先比较、合并，不覆盖后来修改。不把复制文件变成扩大可访问范围或绕过宿主审批的通道。
- 此方法不让 DeepSeek 获得直接网络访问。大型原地处理、跨目录修改或必须联网的命令由有相应权限的主代理接手；需要主代理也不具备的权限时报告阻塞。

## 已发生拒绝

不要仅凭 `rejected by user` 判定用户点了拒绝。区分实际用户拒绝、宿主自动拒绝以及 Windows 文件权限错误。用户真实拒绝或取消时停止；只有已有授权且已查明是技术问题，才由主代理按上述不同执行分工继续，不能重复原来被拒的子代理操作。
